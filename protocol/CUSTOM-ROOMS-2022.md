# Кастомные комнаты 0x737x — подтверждённые форматы (2026-10-24)

Источник: данные партнёра (decrypted application plaintext до TCONN-шифрования,
регрессионные фикстуры). Реализация: `tools/roe_custom_room_2022.py`,
обработка `tools/heartbeat_probe_2022.py` (TCP-фронт 8001), тесты
`tests/test_roe_custom_room_2022.py` (байт-в-байт против фикстур).

## 0x7370 ROOM_LIST_RSP

Заголовок кадра 10 байт (в фикстуре `01 1A C1 66 73 70 00 00 73 70`; seq —
соединительный, наш). Тело, все числа big-endian:

```
u32 page
u32 page_count
u32 room_count
rooms[room_count]:
  u64 room_id
  u64 creator
  string name        # u32 длина (с NUL) + байты; пустая = 00000001 00
  string password
  u32 team_type      # 1 Solo / 4 Squad
  u32 perspective    # 1 TPS / 2 FPP
  u32 zone_id        # из фикстуры: 5 при map 16007
  u32 map_id
  u32 max_actor
  u32 cur_actor
  u32 state          # 1
```

Ответ **задерживается на 100 мс**: панель XVersion RspRoomList отбрасывает
ответы, пришедшие до готовности окна комнаты. Пароль в чужой список не
отдаётся (строка пустая).

Фикстура (одна комната: id 1, creator 0, «Rico», пустой пароль, 1/1, zone 5,
map 16007, 60/1, state 1) — три строки в `test_roe_custom_room_2022.py`
(`LIST_FIXTURE`), сравнение без первых 10 байт (заголовок).

## 0x7371 CREATE_REQ → 0x7372 CREATE_RSP

Запрос (распознаётся, `decode_create`): u32 0, u32 0, u64 uid, строка имени,
строка пароля, 7 слов (mode, perspective, 0, map_id, max_players, 0, 0).

Ответ — **только `u32 result`** (0), без эха идентификатора:
`011ac05c737200007372 00000000`.

Сразу затем сервер шлёт **полный 0x737B ENTER_NTF**: запись комнаты (та же
раскладка, что в списке) + `u32 count` + записи участников. Локальный актёр
входит **только этим сообщением** — через 0x737C OTHER_ENTER_NTF не входит.

## 0x7373 REMOVE_REQ → 0x7374 REMOVE_RSP → 0x737B (пустой)

Формат запроса не подтверждён (принимается 1..16 байт, первые 8 = room_id).

Успешный ответ — `u32 0`: `011ac05e73740000737400000000`.
Одним ответом окно не чистится — следом шлётся пустой снимок 0x737B:
room_id 0, creator 0, пустые строки, нулевые поля, count 0. Нулевой
идентификатор — ветка очистки модели/интерфейса комнаты (фикстура
`ENTER_EMPTY_FIXTURE`). Комната удаляется из списка.

## Не подтверждено

- **Выход 0x7377/0x7378/0x737D**: валидных QUIT_RSP/QUIT_NTF нет. Остаётся
  лучшее предположение (`quit_variants`, `quit_ntf_variants`), клиент
  повторяет запрос, пока не поймёт. Нативный запрос 0x7377 в логах есть.
- **Запись участника ENTER_NTF**: в фикстуру попал только пустой снимок
  (count 0). Используется предположение `u64 uid, u32 len, имя+NUL, 12 слов`.
- Значения zone_id для карт кроме 16007.
